Privacy notice

Maintained by Xule Lin · Updated 29 September 2026

Your music and this tab

The local studio keeps your current notation, pattern code, settings, and undo history in the open page. Reloading starts a new session. Save session downloads a file with both drafts and current sound settings; Open session restores that file without starting playback. Source, audio, and MIDI downloads are requested on your device. This interface does not add analytics or automatically upload compositions to the hosted sharing service.

Working with an agent

A connected browser agent can use WebMCP to read your current music, including unevaluated edits, change it, and control playback. Tool results include source, selections, explanations, proposed edits, settings, status, and errors. Copy for chat puts the selected passage and your question on your clipboard; you decide where to paste them. Your browser or AI host may retain those interactions under its own policies; this local page does not control that retention.

Network requests

Local does not mean offline. The studio loads fonts from Google Fonts, and its music engines can load scripts, soundfonts, and samples from providers such as unpkg, jsDelivr, and GitHub Pages. Those providers receive normal request information, including your IP address and browser information. Some sample features use additional providers.

Strudel patterns run as JavaScript inside the music frame and can request URLs specified by their code. The frame is sandboxed, but it can access the network. Review unfamiliar code before playing it.

Storage and other versions

Music runs in isolated frames with restricted access to browser storage. The page does not save drafts automatically. It warns about changes since opening or the last requested session export when the browser permits an exit warning. Downloads, browser caches, and records held by your AI host can outlast the session.

The project privacy policy describes the separate hosted MCP service, optional sharing, reference search, and storage used by other player configurations. Those features have different data flows from this local workspace.
